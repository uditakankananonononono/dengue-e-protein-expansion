# dengue-e-protein-expansion
E-protein mutations across recent (2023+) global dengue isolates and their effects on known
antibody epitopes; ties to why reinfections can be worse. Open public data only (NCBI Virus,
Nextstrain, RCSB PDB). Layout: denv1-2/ (builder 14), denv3-4/ (builder 15: DENV-3 + DENV-4
atlas + cross-serotype synthesis). Each slice: code/, data/ (byte-locked manifests),
results/, paper/. Top-level MANIFEST.sha256 updated at seal.
